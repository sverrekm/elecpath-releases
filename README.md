# Elecpath

Ferdige Windows-versjoner av Elecpath, et program for elskjema og skaparrangement.
Dette repoet har bare utgivelsene, ikke kildekoden.

## Installere

1. Last ned `Elecpath-x.y.z-win64.zip` fra siste versjon under [Releases](../../releases/latest).
2. Pakk ut hele zip-filen til en mappe.
3. Start `Elecpath.exe` i mappen.

Programmet er ikke signert. Windows kan vise «Windows beskyttet PC-en»: velg **Mer informasjon** og **Kjør likevel**.

## Oppdatere

I programmet: **Hjelp > Se etter oppdateringer**. Ingen innlogging trengs.
